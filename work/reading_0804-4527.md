# Topological surface states in three-dimensional magnetic insulators
- **arXiv ID**: arXiv:0804.4527
- **Authors**: Joel E. Moore, Ying Ran, Xiao-Gang Wen
- **Year**: 2008
- **Source**: literature/papers/0804.4527/

## 研究との関連性
Hopf絶縁体の原論文であり、Hopf不変量のバンド理論における定義、具体的なタイトバインディングモデル、表面状態の数値研究を含む。我々の研究の基盤となる論文。

## 抽出内容

### 1. Hopf不変量の定義

**一般的なバンド絶縁体の位相分類の枠組み**: $d$次元で$n$本の占有バンドと$m$本の空バンドを持つバンド絶縁体は、$\boldsymbol{k}$空間で$(m+n)$次元行列$H(\boldsymbol{k})$で記述される。固有値を$+1$と$-1$に変形すると

$$H(\boldsymbol{k}) = W(\boldsymbol{k}) I_{m,n} W^\dagger(\boldsymbol{k})$$

となり、$H(\boldsymbol{k})$はターゲット空間

$$M_{m,n} = SU(m+n) / [SU(m) \times SU(n) \times U(1)]$$

上の点に対応する。バンド絶縁体の位相分類は写像$T^d \to M_{m,n}$の分類に帰着する。

**2バンドの場合**: $M_{1,1} = S^2$。3次元BZは$T^3$であり、$\pi_3(S^2) = \mathbb{Z}$からHopf不変量が現れる。具体的にはBloch Hamiltonian

$$H(\boldsymbol{k}) = a_1(\boldsymbol{k})\sigma_x + a_2(\boldsymbol{k})\sigma_y + a_3(\boldsymbol{k})\sigma_z + a_4(\boldsymbol{k})\mathbf{1}$$

において($a_4$は位相分類に無関係)、単位ベクトル場

$$\hat{\boldsymbol{n}}(\boldsymbol{k}) = \frac{(a_1, a_2, a_3)}{\sqrt{a_1^2 + a_2^2 + a_3^2}}$$

を定義する。"current"を

$$j_\mu = \frac{1}{8\pi} \epsilon_{\mu\nu\lambda} \hat{\boldsymbol{n}} \cdot (\partial_\nu \hat{\boldsymbol{n}} \times \partial_\lambda \hat{\boldsymbol{n}})$$

と定義し、Berry fluxと一致することを示している。Hopf不変量は

$$n_h = -\int d^3k\, \boldsymbol{j} \cdot \boldsymbol{A}$$

で与えられる。ここで$\boldsymbol{A}$は$\nabla \times \boldsymbol{A} = \boldsymbol{j}$を満たすゲージ場である。この被積分関数はAbel的Chern-Simons形式であり、全Chern数がゼロのとき完全にゲージ不変である。

**Chern数との関係**: $T^3$上の写像$T^3 \to S^2$は、内在する3つの2次元トーラスそれぞれにChern数を持ちうる。Chern数が非ゼロのとき、Hopf不変量は整数ではなく有限群$\mathbb{Z}_{2 \cdot \text{GCD}(n_x, n_y, n_z)}$に値をとる（Pontryagin）。本論文ではChern数がすべてゼロの場合に注目。

**Hopf不変量の幾何学的描像**: $S^2$上の各点の逆像は$T^3$中の円であり、異なる2点からの2つの円の**リンク数**がHopf不変量に等しい。

**数値計算アルゴリズム**: 実空間で$\boldsymbol{j}$を離散化し、Fourier変換して運動量空間で$\partial_\mu A_\mu = 0$ゲージにおいて静磁気方程式を解く。BZ上の$N$点に対して$O(N \log N)$アルゴリズム。

### 2. モデルハミルトニアン

具体的なタイトバインディングモデル:

$$z_\uparrow = \sin k_x + i \sin k_y$$
$$z_\downarrow = \sin k_z + i\left(\cos k_x + \cos k_y + \cos k_z - \frac{3}{2}\right)$$
$$v^i = \boldsymbol{z}^\dagger \sigma^i \boldsymbol{z}, \quad H = \boldsymbol{v} \cdot \boldsymbol{\sigma}$$

このモデルの特徴:
- Hopf写像に連続的に接続されるよう構成されているが、低いFourier成分のみを持ち局所的タイトバインディング表現を実現
- Hopf不変量 = +1、全Chern数 = 0
- $E \leftrightarrow -E$対称性（$a_4 = 0$のため）
- バンドギャップ: $-0.25 < E < 0.25$

実空間では3種類のホッピングを含む:
- オンサイトZeeman相互作用: $-13\sigma_z/4$
- 最近接スピン依存ホッピング: 強度$3\lambda/2$
- 次近接（長さ2）スピン依存ホッピング: 強度$\lambda/2$

パラメータ$\lambda$でホッピング項を制御すると、$\lambda \approx 0.63$から$\lambda \approx 0.82$の範囲でギャップが閉じ、Hopf不変量の相転移が確認された。

### 3. 表面状態の数値結果

(001)、(010)、(100)方向の急峻な境界に対して中間ギャップ表面状態を数値計算。結果:
- **全方向で分散的なギャップレス表面状態が存在** -- 単一の中間ギャップバンドから生じる
- **(010)および(100)方向**: $\Gamma$点 $(0,0)$ に単一のDirac点
- **(001)方向**: ギャップレス点のリング（点ではなく環）が存在。粒子-正孔対称性を破る摂動を加えると、リング上の異なる点でバンド交差エネルギーがシフトする

**QBT（二次バンド接触）について**: 本論文では表面状態の分散が**二次的（quadratic）**であるとは明示的に述べていない。Dirac点（線形分散）に言及しているが、(001)方向のギャップレスリングの分散の詳細は示されていない。QBTは本論文では議論されておらず、後の研究で見出されたものと考えられる。

### 4. 十重対称性分類からの逸脱の理由

著者らの議論:
- **時間反転対称性を必要としない**: Hopf絶縁体は磁性背景中の電子を記述し、時間反転対称性を**破る**必要がある（ブリルアン域の時間反転不変点$\boldsymbol{k} = -\boldsymbol{k}$でKramers縮退を避けるため）
- **Avron-Seiler-Simon (ASS)の定理**: バンド構造の"extensive"な不変量（バンド数に線形な不変量）はChern数から導かれるものだけであり（時間反転不変系の4次元不変量を除く）、Hopf不変量はこの分類に属さない
- **2バンド固有の性質**: ターゲット空間が$M_{1,1} = S^2$となるのは2バンドの場合のみで、$\pi_3(S^2) = \mathbb{Z}$がHopf不変量を生む。多バンドへの一般化は困難（後述）

### 5. 2バンド条件の必要性

- $M_{1,1} = S^2$は2バンドモデル特有であり、この場合にのみ$\pi_3(S^2) = \mathbb{Z}$からHopf分類が生じる
- **多バンドへの一般化の困難**: 非Abel的Chern-Simons形式の積分は、縮退した占有バンドがある場合にゲージ依存になる（大きなゲージ変換のもとで整数だけ変化する）。これはIQHEやZ$_2$絶縁体のChern数やChernパリティとは対照的
- コメントアウトされた部分に$\pi_3(M_n) = \mathbb{Z}$の証明のスケッチがあり（$\pi_3(SU(n)) = \mathbb{Z}$を利用）、任意のバンド数でも**1つの**整数値不変量が存在することを示唆。ただし、Fermi準位から離れたバンドの縮退を許すと一部のHopf絶縁体が自明な絶縁体に接続されうるため、**半充填の2バンドの場合が常に頑健**である（2本のバンドがFermi準位を横切らずに縮退することが不可能なため）

### 6. 位相的保護と対称性

- Hopf不変量は**対称性による保護を必要としない** -- Z$_2$絶縁体の時間反転対称性とは異なり、Hopf絶縁体は磁性（時間反転を破る）系で実現される
- ギャップが閉じない限りHopf不変量は変化しない（ホモトピー不変量であるため）
- ただし**乱れに対する安定性は不明確**: 著者らは、表面状態が乱れに安定であるためには表面理論に何らかの位相的不変量が必要だが、明らかな表面不変量がないと指摘。表面状態は局在化する可能性が高いが、光電子分光やトンネル実験、クリーンな試料では観測可能かもしれないと述べている

### 7. 物理的予測

本論文で述べられている予測:
- **ギャップレス表面状態**: 滑らかな（断熱的な）境界では必ずギャップレス励起が存在する。急峻な境界でも数値的にギャップレス表面状態が確認された
- **材料候補**: パイロクロア格子化合物（非共線的磁気秩序を持つフラストレート磁性体）、特にR$_2$Mo$_2$O$_7$（Rは希土類イオン）が現実的候補。ペロブスカイトマンガナイトも候補
- **光格子中の超冷却原子**によるシミュレーションの可能性にも言及
- **コメントアウトされた部分に含まれる予測**（公式版には不含だが、著者の考えとして記録）:
  - アクシオン電気力学による有効理論: $\Delta\mathcal{L} = \frac{e^2 n}{2\pi} F_{\mu\nu}\tilde{F}^{\mu\nu}$
  - 境界での面電荷蓄積: $(\Delta n) e^2 B / 2\pi$
  - 壁面内のHall電流: $e^2 E (\Delta n) / 2\pi$
