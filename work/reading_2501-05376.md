# Correlated Hopf Insulators
- **arXiv ID**: arXiv:2501.05376
- **Authors**: Konstantinos Ladovrechis, Shouvik Sur
- **Year**: 2025
- **Source**: literature/papers/2501.05376/

## 我々の研究との関連性
本論文はHopf絶縁体のトポロジカル量子臨界点(TQCP)における二次バンド接触(QBT)と、2次元QBT半金属およびLuttinger半金属との直接的な対応関係を確立しており、我々の研究テーマ（Hopf絶縁体表面QBTとQBT相互作用系の接続）の中心的な文献である。特に、TQCP上のBerry dipoleの構造とRG解析は、$c=-2$ CFTとの接続を探索する上で重要な足がかりとなる。

## 抽出内容

### 1. モデル: Hopf絶縁体ハミルトニアン

Moore-Ran-Wenモデルを使用。Blochハミルトニアンは

$$H_0(\vec{k}, m) = \vec{w}(\vec{k}, m) \cdot \vec{\sigma}$$

ここで

$$\vec{w}(\vec{k}, m) = \begin{pmatrix} 2u_1 u_3 + 2u_2 u_4 \\ 2u_1 u_4 - 2u_2 u_3 \\ u_1^2 + u_2^2 - u_3^2 - u_4^2 \end{pmatrix}$$

$u_1(\vec{k}) = t \sin k_x$, $u_2(\vec{k}) = t \sin k_y$, $u_3(\vec{k}) = t \sin k_z$, $u_4(\vec{k}, m) = t_0[\cos k_x + \cos k_y + \cos k_z - m]$（$t_0 = 1$をエネルギー単位とする）。Pauli行列は副格子自由度 $A$, $B$ に作用する。

**対称性**: $\hat{k}_z$軸周りの4回回転対称性 $\mathcal{C}_4^z$ が

$$\mathcal{C}_4^z: H_0(\vec{k}, m) \mapsto H_0(k_y, -k_x, k_z, m) = e^{i\frac{\pi}{4}\sigma_3} H_0(\vec{k}, m) e^{-i\frac{\pi}{4}\sigma_3}$$

で与えられる。また、反ユニタリー鏡映操作 $\mathcal{M}_x \mathcal{T}$, $\mathcal{M}_y \mathcal{T}$ も存在する。

**位相図**: $|m| < 3$ ではHopf絶縁相が3つ存在し、$m = \pm 1$ のTQCPで分離される。$m = \pm 3$ のTQCPではHopf invariant $-1$ の相と通常の絶縁体が分離される。

### 2. TQCP上の有効理論とQBT

$m = 3$ のTQCPに焦点を当てる。$\Gamma$点周りの $k \cdot p$ 展開による有効ハミルトニアンは

$$h_0(\vec{k}, \delta_b) = 2[t^2 k_x k_z + t k_y \delta_b]\sigma_1 + 2[t^2 k_y k_z - t k_x \delta_b]\sigma_2 + [t^2(k_x^2 + k_y^2 - k_z^2) - \delta_b^2]\sigma_3$$

ここで $\delta_b = m - 3$ はトポロジカル質量パラメータ。$\delta_b = 0$ でBrillouin zone中心に二次バンド接触が実現する。

**トポロジカル質量の特異な形式**: $[2tk_y\sigma_1 - 2tk_x\sigma_2]\delta_b - \delta_b^2\sigma_3$ と、3つのPauli行列全てにまたがる。逆Hopf写像を通じて、中心対称3次元強トポロジカル絶縁体のDirac点のトポロジカル質量に関連する。

**創発的 $z$-鏡映対称性**: TQCP ($\delta_b = 0$) において $\mathcal{M}_z$ 対称性が創発する:

$$\mathcal{M}_z: h_0(\vec{k}, 0) \mapsto h_0(k_x, k_y, -k_z, 0) = \sigma_3 h_0(\vec{k}, 0) \sigma_3$$

この対称性は有限の $\delta_b$ と $O(|\vec{k}|^3)$ の項で破れる。前者は関連摂動、後者は非関連。

### 3. Berry dipole構造

QBTは **Berry dipole** として機能する。Gaussian球面上のBerry曲率の径方向成分は

$$B_r(|\vec{k}|, \theta, \phi) = \frac{\cos\theta}{\pi |\vec{k}|^2}$$

- 正味Berry fluxはゼロ（Berry単極子ではない）
- staggered Berry flux $\mathfrak{C}_{\text{stagg}} = 2$（$2\pi$単位）: 北半球と南半球が大きさ $2\pi$ の反対符号のBerry fluxを囲む
- この量子化されたBerry dipoleモーメントは創発的 $z$-鏡映対称性に保証される

### 4. 他のモデルとの接続（極めて重要）

#### 4a. 2次元QBT半金属との接続

TQCP上のハミルトニアンを $d$ 次元に一般化:

$$h'_{0,d}(\vec{k}) = 2t^2 k_d \vec{k}_\perp \cdot \vec{\gamma} + t^2(k_d^2 - k_\perp^2)\gamma_d$$

ここで $\vec{k}_\perp = (k_1, \ldots, k_{d-1})$。

- $d = 3$: Hopf絶縁体のTQCP
- $d = 2$: Bernal積層2層グラフェンやcheckerboard格子に現れる2次元QBT半金属

**次元チューニング**: $\vec{k}_\perp$ の成分数を連続的に変化させることで、$d = 2$ と $d = 3$ のQBTを接続する。

#### 4b. Luttinger半金属との接続

$d_Q = 3$ を固定し、$\gamma_n$ の表現次元を2から4に上げることでLuttinger半金属に接続:

$$h''_{0,3}(\vec{k}) = t' k_z \vec{k}_\perp \cdot \vec{\gamma} + t'(2k_z^2 - k_\perp^2)\gamma_3 + t'' k_x k_y \gamma_4 + t''(k_x^2 - k_y^2)\gamma_5$$

- $t'' = 0$ のQBTは **反対符号Berry dipoleの2コピー** と見なせる（Dirac半金属において1つのDirac点が反対電荷のWeyl点の2コピーに対応するのと類似）
- 材料例: $\alpha$-tin, pyrochlore iridate, half-Heusler化合物

### 5. 相互作用項とFierz完全基底

$\mathcal{C}_4^z$ 対称性下で許容される最も一般的な局所相互作用は、Fierz変換の制約により **1つの独立チャネル** に還元される:

$$L_{\text{int}} = g \sum_{\vec{R}} [\hat{\Psi}^\dagger(\vec{R},\tau) \hat{\Psi}(\vec{R},\tau)]^2$$

これはオンサイト斥力Hubbard相互作用 $\sum_{\vec{R}} \hat{n}_A(\vec{R},\tau) \hat{n}_B(\vec{R},\tau)$ と等価。

Fierz変換の制約: $v = 2s_{22} = -2s_{11}$, $s_{21} = 0$。

### 6. くりこみ群(RG)解析

#### スケーリング次元

- $[k_j] = L^{-1}$, $[k_0] = L^{-2}$, $[t] = L^0$, $[\Psi] = L^{(4+d)/2}$
- 裸の動的臨界指数 $z = 2$
- $[\delta_b] = L^{-1}$（関連摂動）
- $[g] = L^{d-2}$（$d < 2$ でのみ関連 → 上部臨界次元 $d_c = 2$）

#### $\epsilon$-展開スキーム

$d = 2 + \epsilon$ で展開。Wilsonian RGを用い、角度部分のFeynman積分は $d = 3$ で評価。

#### ベータ関数

$$\beta_{\widetilde{\Delta}} = \widetilde{\Delta}\left[2 + \frac{8\widetilde{g}}{3t^2}\right]$$

$$\beta_{\widetilde{g}} = -\epsilon\widetilde{g} + \frac{2\widetilde{g}^2}{t^2}$$

ここで $\widetilde{g} = g(\Lambda/\ell)^{d-2}/(8\pi^2)$、$\widetilde{\Delta} := \widetilde{\delta}_b^2 - \widetilde{\Delta}_{\text{TQCP}}$（$\widetilde{\Delta}_{\text{TQCP}} = \widetilde{g}(1-\ell^{-2})/(24\pi^2)$はTQCPのシフト）。

#### 固定点

$$(\widetilde{\Delta}_G, \widetilde{g}_G) = (0, 0) \quad \text{(Gauss固定点: 臨界点)}$$

$$(\widetilde{\Delta}_\star, \widetilde{g}_\star) = \left(0, \frac{t^2\epsilon}{2}\right) \quad \text{(Wilson-Fisher型: 双臨界点)}$$

- Gauss固定点: $\widetilde{\Delta}$ 方向のみ不安定（臨界点）
- $(\widetilde{\Delta}_\star, \widetilde{g}_\star)$: 両方向に不安定（双臨界点）
- 流れの構造はIsing模型の $d > 4$ における $\phi^4$ 理論のWilson-Fisher固定点と定性的に類似

#### 帰結

- $\widetilde{g} < \widetilde{g}_\star$: 非相互作用相（Hopf絶縁体/通常絶縁体/QBT半金属）に流れる
- $\widetilde{g} > \widetilde{g}_\star$: 強結合不安定性へ流れる

### 7. 帯磁率解析と支配的不安定性

ソース項 $M_j \bar{\Psi}\gamma_j\Psi$（$j = 0, 1, 2, 3$）のRG方程式:

$$\frac{d\ln\widetilde{M}_0}{d\ln\ell} = 2, \quad \frac{d\ln\widetilde{M}_1}{d\ln\ell} = 2 + \frac{22\widetilde{g}}{15t^2}, \quad \frac{d\ln\widetilde{M}_2}{d\ln\ell} = 2 + \frac{22\widetilde{g}}{15t^2}, \quad \frac{d\ln\widetilde{M}_3}{d\ln\ell} = 2 + \frac{16\widetilde{g}}{15t^2}$$

- $M_1$ と $M_2$ チャネルが縮退し、**支配的不安定性**を構成
- 対称性の破れた状態: $\cos\theta \langle\bar{\Psi}\sigma_x\Psi\rangle + \sin\theta \langle\bar{\Psi}\sigma_y\Psi\rangle$（$\theta \in [0, 2\pi]$）
- この縮退は $\hat{k}_z$ 軸周りの4回回転対称性に起因
- **ネマティック性**: 4回回転対称性が自発的に破れ、空間異方性が生じる
- 2次元極限では縮退が解け、$\langle\bar{\Psi}\sigma_y\Psi\rangle$ が支配的 → 異常Hall絶縁体（Sun et al. 2009と一致）
- 異常次元は $\widetilde{\Delta}$（トポロジカル質量）に依存しない → TQCPの近傍でも離れた場所でも同じ帯磁率解析が成立

### 8. 相図と新相

#### 平均場ハミルトニアン

$$H_{\text{MF}}(\vec{k}, m) = H_0(\vec{k}, m) + M\cos\theta\,\sigma_1 + M\sin\theta\,\sigma_2$$

#### Weyl半金属相

- TQCPにおける回転対称性の自発的破れにより、QBTが **Berry単極子電荷 $\pm 1$ のWeyl点対** に分裂
- $M$ がWeyl点の間隔を、$\theta$ が主軸に対する角度方位を制御
- Weyl点は反転対称性、鏡映対称性、時間反転対称性の全てを欠くため、高度に異方的に分布（Fig. 3）
- 全ての標準的な表面終端でFermi arcが出現

#### ネマティック絶縁体

- WSM相はHopf絶縁体側（$m < 3$）とtrivial絶縁体側（$m > 3$）でネマティック絶縁体相に挟まれる
- **Nematic insulator #1**（$m < 3$ 側）: RTP不変量がHopf絶縁体の半分。$X - \Gamma$ パスでは $P_z$ が完全に巻くが、$M - \Gamma$ では半巻きのみ
- **Nematic insulator #2**（$m > 3$ 側）: trivial絶縁体との明確なトポロジカル区別なし
- WSMとネマティック絶縁体間の相転移はWeyl点の合体で特徴づけられる → **TQCPの線**を形成

#### 次元間の接続（Fig. 2）

$d_Q = 2$ と $d_Q = 3$ を補間する相互作用相図:

- $d_Q = 2$: QBT半金属は任意に弱い相互作用に対して不安定 → Chern絶縁体
- $d_Q = 3$: QBT半金属は摂動的に安定 → 強い相互作用でネマティックWeyl半金属
- 2次元のChern絶縁層は3次元のWSM内のWeyl点を分離するChern数を持つ面として埋め込まれる

### 9. トポロジーと表面状態

#### WSM相

- $\theta = 0$ の場合、Weyl点は $[100]$ と $[01\bar{1}]$ 軸で張られる面上に位置
- Weyl点を分離する面（$k_x$-$k_y$ 面と $k_x$-$k_z$ 面の2種類）が非自明なChern数を持つ
- 各面は3次元Brillouin zone内に埋め込まれた2次元Chern絶縁体と見なせる
- $(100)$ 表面でFermi arcが確認された

#### ネマティック絶縁体相

- RTP不変量による診断
- Hopf絶縁体では $P_z(k_x, k_y) = \frac{1}{\pi}\int_{-\pi}^{\pi} dk_z\, A_z(\vec{k})$ が $X-\Gamma$ と $M-\Gamma$ の両方で $0 \to 1 \to 0$ と巻く
- Nematic insulator #1: $X-\Gamma$ のみ完全巻き
- RTP不変量にrobustなbulk-boundary対応は存在しないため、ネマティック絶縁体の表面状態はトポロジカルに保護されない

### 10. 非相反超伝導

- 回転対称性の破れた状態のバンド構造は反転非対称: $\varepsilon_s^{\text{MF}}(-\vec{k}) \neq \varepsilon_s^{\text{MF}}(\vec{k})$
- ドープすると非相反金属 → 超伝導対形成で超伝導ダイオード効果が実現可能
- BdGハミルトニアン:

$$H_{\text{BdG}}(\vec{k}, m) = \begin{pmatrix} H_0(\vec{k}, m) - \mu & \Delta_{\text{sc}}\sigma_2 \\ \Delta_{\text{sc}}\sigma_2 & \mu - H_0^*(-\vec{k}, m) \end{pmatrix}$$

- $M > \Delta_{\text{sc}}$ の条件下でBogoliubov-Fermi面が出現

### 11. Luttinger半金属との関連（結論より）

- TQCPのQBTはLuttinger半金属のQBTの**2バンド版**
- Luttinger半金属も強い斥力相互作用下でネマティック状態を実現する（Goswami, Roy, Das Sarma 2017を参照）
- 将来課題として、本論文の相関物理がLuttinger半金属でどの程度生き残るか、特にBerry dipoleが相関駆動現象に与える影響の調査を提案

## 我々の研究へのキーポイント

1. **QBT at TQCP**: Hopf絶縁体のTQCP上でQBTが実現し、そのBerry曲率は双極子型（$\cos\theta/\pi|\vec{k}|^2$）。これはHopf不変量と直接結びつく
2. **2D QBTとの次元接続**: 3次元のTQCPが2次元のQBT半金属（$c = -2$ CFTが記述する系）と次元チューニングで接続される。$\epsilon$展開パラメータが物理的に2次元QBT相図と3次元相図を補間する
3. **相互作用効果の質的差異**: 2次元では任意に弱い相互作用でChern絶縁体、3次元では強い相互作用が必要でWeyl半金属。上部臨界次元は $d_c = 2$
4. **Luttinger半金属は表現の拡大**: 2次元表現 → 4次元表現（$\gamma$ 行列）で、Hopf TQCPからLuttinger半金属に自然に接続
5. **表面QBTの直接研究は行われていない**: ネマティック絶縁体の表面状態はトポロジカルに保護されないとして詳細な解析を行っていない。WSM相のFermi arcは議論されたが、元のHopf絶縁体の表面QBTについては本論文では扱っていない
