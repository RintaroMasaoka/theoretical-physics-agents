# Hopf Insulators and Their Topologically Protected Surface States
- **arXiv ID**: arXiv:1307.7206
- **Authors**: Dong-Ling Deng, Sheng-Tao Wang, Chao Shen, Lu-Ming Duan
- **Year**: 2013
- **Source**: literature/papers/1307.7206/

## 研究との関連性
Hopf絶縁体の格子模型を任意のHopfインデックスに対して系統的に構築し、表面状態の存在・ロバスト性を数値的に検証した論文。我々の研究における表面QBTの基礎となる模型と表面状態の詳細を与える。

## 抽出内容

### 1. 格子模型の系統的構築

任意の整数Hopfインデックス $\chi$ を持つHopf絶縁体を実現するtight-binding模型を構築する。2バンドハミルトニアンは一般に
$$\mathcal{H}(\mathbf{k}) = \mathbf{u}(\mathbf{k}) \cdot \boldsymbol{\sigma}$$
と書ける（$\boldsymbol{\sigma} = (\sigma^x, \sigma^y, \sigma^z)$ はPauli行列、エネルギーシフト項 $u_0(\mathbf{k})\mathbf{I}_2$ は省略）。エネルギー分散は $E(\mathbf{k}) = \pm |\mathbf{u}(\mathbf{k})|$ であり、$|\mathbf{u}(\mathbf{k})| > 0$ のときギャップが開く。

構築は2段階の写像の合成による：

**ステップ1：一般化Hopf写像 $f: \mathbb{S}^3 \to \mathbb{S}^2$**

互いに素な整数 $p, q$ に対して、Whitehead (1947) の一般化Hopf写像を用いる：
$$x + iy = 2\lambda \eta_\uparrow^p \bar{\eta}_\downarrow^q, \quad z = \lambda(|\eta_\uparrow|^{2p} - |\eta_\downarrow|^{2q})$$
ここで $\eta_\uparrow, \eta_\downarrow$ は $|\eta_\uparrow|^2 + |\eta_\downarrow|^2 = 1$ を満たす $\mathbb{R}^4$ の複素座標、$\lambda = 1/(|\eta_\uparrow|^{2p} + |\eta_\downarrow|^{2q})$ は正規化因子。この写像のHopfインデックスは $\pm pq$（$\mathbb{S}^3$ の向きで符号が決まる）。

**ステップ2：写像 $g: \mathbb{T}^3 \to \mathbb{S}^3$**
$$\eta_\uparrow(\mathbf{k}) = \sin k_x + it \sin k_y$$
$$\eta_\downarrow(\mathbf{k}) = \sin k_z + i(\cos k_x + \cos k_y + \cos k_z + h)$$
ここで $t$ と $h$ は定数パラメータ。

合成写像 $f \circ g$ から得られる $\mathbf{u}(\mathbf{k})$ は：
$$\mathbf{u}(\mathbf{k}) = |\mathbf{u}(\mathbf{k})| \left(\text{Re}[2\eta_\uparrow^p \bar{\eta}_\downarrow^q],\; \text{Im}[2\eta_\uparrow^p \bar{\eta}_\downarrow^q],\; |\eta_\uparrow|^{2p} - |\eta_\downarrow|^{2q}\right)$$
$|\mathbf{u}(\mathbf{k})| = 1/\lambda(\mathbf{k})$。このハミルトニアンは $\sin(\mathbf{k})$ と $\cos(\mathbf{k})$ の $(p+q)$ 次多項式であり、実空間ではtight-bindingモデルに対応する。スピン軌道結合とスピン依存ホッピング項を含む。

$p = q = 1$, $(t,h) = (1, -3/2)$ の場合、Moore-Ran-Wen (2008) の模型に帰着する。

### 2. 位相図

Hopfインデックスはパラメータ $(p, q, t, h)$ に応じて以下の値を取る：
$$\chi(\hat{\mathbf{u}}) = \Gamma(g) \cdot \chi(f) = \pm pq \cdot \Gamma(g)$$
ここで $\Gamma(g)$ は写像 $g: \mathbb{T}^3 \to \mathbb{S}^3$ の巻き付き数であり：
$$\Gamma(g) = \frac{1}{12\pi^2} \int_{\text{BZ}} d\mathbf{k}\; \epsilon_{\alpha\beta\gamma\rho} \epsilon_{\mu\nu\tau} \frac{1}{|\boldsymbol{\eta}|^4} \boldsymbol{\eta}_\alpha \partial_\mu \boldsymbol{\eta}_\beta \partial_\nu \boldsymbol{\eta}_\gamma \partial_\tau \boldsymbol{\eta}_\rho$$
直接計算の結果：
$$\Gamma(g) = \begin{cases} 0, & |h| > 3 \\ 1, & 1 < |h| < 3 \text{ かつ } t > 0 \\ -2, & |h| < 1 \text{ かつ } t > 0 \end{cases}$$

位相図の特徴：
- $h = 0$ に関して鏡映対称、$t = 0$ に関して反対称
- $|h| > 3$ ではトポロジカルに自明な相 ($\chi = 0$) のみ
- $1 < |h| < 3$ で $\chi = \pm pq$、$|h| < 1$ で $\chi = \pm 2pq$
- $p, q$ は任意の互いに素な整数なので、$\chi$ は任意の整数値を取りうる

### 3. Hopfインデックスの数値計算法

Hopfインデックスは以下の積分で定義される（Chern数がゼロの場合）：
$$\chi(\hat{\mathbf{u}}) = -\int_{\text{BZ}} \mathbf{F} \cdot \mathbf{A}\; d\mathbf{k}$$
ここで $\mathbf{F}$ はBerry曲率：
$$F_\mu = \frac{1}{8\pi} \epsilon_{\mu\nu\tau} \hat{\mathbf{u}} \cdot (\partial_\nu \hat{\mathbf{u}} \times \partial_\tau \hat{\mathbf{u}})$$
$\mathbf{A}$ はBerry接続で $\nabla \times \mathbf{A} = \mathbf{F}$ を満たす。$\chi$ はゲージ不変。

計算はMoore-Ran-Wen (2008) の方法に従い、トーラス $\mathbb{T}^3$ の離散化によって行う。グリッド数を増やすとChern数は速やかにゼロに収束し、Hopfインデックスは整数値 $\pm pq$ または $\pm 2pq$ に収束する。

### 4. Chern数がゼロであることの解析的証明

論文のAppendixにおいて、$C_\mu = 0$ ($\mu = x, y, z$) を解析的に証明している。証明はパリティ議論による。

$k_x$ を固定した断面について $C_x = \int dk_y dk_z\; F_x(k_y, k_z) = 0$ を示す。$g_1 = \sin k_x$, $g_2 = t \sin k_y$, $g_3 = \sin k_z$, $g_4 = \cos k_x + \cos k_y + \cos k_z + h$ とすると、$(k_y, k_z) \to (-k_y, -k_z)$ の変換に対するパリティは $P[g_1] = P[g_4] = 1$, $P[g_2] = P[g_3] = -1$。

一般化Hopf写像の構造から、$P[\hat{u}_x] = (-1)^q$, $P[\hat{u}_y] = -P[\hat{u}_x]$, $P[\hat{u}_z] = 1$ が導かれ、結果として
$$P[F_x] = P\left[\hat{\mathbf{u}} \cdot (\partial_{k_y} \hat{\mathbf{u}} \times \partial_{k_z} \hat{\mathbf{u}})\right] = -1$$
奇パリティなので積分するとゼロ。同様の議論で $C_y = C_z = 0$。

### 5. 表面状態

$(001)$ 方向に $N_z$ サイトのスラブを取り、$(x, y)$ 方向に周期境界条件を保つ。$k_z$ について逆フーリエ変換し、各 $(k_x, k_y)$ に対して $2N_z \times 2N_z$ 行列を対角化する。

**明示的なスラブハミルトニアンの行列要素** (Supplemental Material)：

$A = 2(\sin k_x + it \sin k_y)^p$, $B = -i(\cos k_x + \cos k_y + h)$ とおくと
$$u_x + iu_y = A(-ie^{ik_z} + B)^q = \sum_{\kappa=0}^{q} D_\kappa e^{i\kappa k_z}$$
$$D_\kappa = A \binom{q}{\kappa} (-i)^\kappa B^{q-\kappa}$$

$u_z$ についても同様に $R = (\sin^2 k_x + t^2 \sin^2 k_y)^p$, $S = 1 + (\cos k_x + \cos k_y + h)^2$, $T = (\cos k_x + \cos k_y + h)$, $Q = S/T$ として三項展開する。

逆フーリエ変換後の行列要素：
$$t_{2k, 2l}^{k_x, k_y} = R\delta_{k,l} - \sum_{\alpha+\beta+\kappa=q} J_{\alpha\beta\kappa q} \delta_{2k, 2l+\alpha-\beta}$$
$$t_{2k-1, 2l-1}^{k_x, k_y} = -R\delta_{k,l} + \sum_{\alpha+\beta+\kappa=q} J_{\alpha\beta\kappa q} \delta_{2k, 2l+\alpha-\beta}$$
$$t_{2k-1, 2l}^{k_x, k_y} = \sum_{\kappa=0}^{q} D_\kappa \delta_{2k-1, 2l+\kappa}$$
$$t_{2k, 2l-1}^{k_x, k_y} = \sum_{\kappa=0}^{q} D_\kappa^* \delta_{2k+\kappa, 2l-1}$$

**表面状態の数値結果**：
- $(p,q) = (1,2)$, $(t,h) = (1, 1.5)$ で200サイトスラブ：$(k_x, k_y) = (0.72, 0.72)$ において**4つの表面状態**が観測される（$\chi = 2$）
- $(p,q) = (1,3)$, $(t,h) = (1, 1.5)$：**6つの表面状態**（$\chi = 3$）
- 表面状態のエネルギーはバルクギャップ内に存在し、ゼロエネルギーモードも含む
- 表面状態の波動関数は境界に鋭いピークを持つ（局在している）

### 6. 表面バンド接触の性質 (QBTについて)

論文は表面状態の分散関係の詳細（二次的か線形かなど）を**明示的に特徴づけていない**。表面状態が「ゼロエネルギーモード」を持つことは報告されているが、バンド接触点の分散がquadraticであるかどうかは議論されていない。固定 $(k_x, k_y)$ でのエネルギースペクトルの図のみが示されており、$(k_x, k_y)$ 全体にわたる分散関係は描かれていない。

ただし、表面状態数と $(k_x, k_y)$ の関係を示すSupplemental Materialの図（Fig. S1）では、$(k_x, k_y)$ の値によって表面状態の数が変化し、あるコンターに沿ってバンドがバルクに溶け込むことが示されている。

### 7. トポロジカル保護と $U(1)$ 対称性

**論文の主張**：Hopf絶縁体は、$U(1)$ 電荷保存則以外のいかなる対称性も必要としない3次元トポロジカル相である。

根拠：
- Hopfインデックスは $\pi_3(\mathbb{G}_{1,2}) = \pi_3(\mathbb{S}^2) = \mathbb{Z}$ に由来する。$m = n = 1$（1つの充満バンドと1つの空バンド）のときのみ非自明で、$(m,n) \neq (1,1)$ では $\pi_3(\mathbb{G}_{m,m+n}) = \{0\}$。
- 保護に必要なのは「バンド数が2であること」と「$U(1)$ 電荷保存」のみ。time reversal、particle-hole、chiral対称性は**不要**。
- Hopf絶縁体はtopological insulatorの周期表（Kitaev 2009, Schnyder et al. 2008）の**外側**に位置する。

**数値検証**：ランダム摂動（$U(1)$ 対称性のみ保持、他の対称性は破る）を加えても、バルクギャップが閉じない限り表面状態は残る。バルク状態の波動関数は摂動下で大きく変化するが、表面状態の波動関数は安定で境界にピークを持ち続ける。

**注意点**（論文が明示的に指摘）：
- 鋭い境界ではバンド数が明確に定義されず、2バンド条件が表面で破れる可能性があるが、それでも数値的にはギャップレス表面状態が存在する。なぜそうなるかの直感的説明は与えられていない。
- 表面状態はクリーンな結晶では extended/metallic だが、ディスオーダー下での局在化からの保護については未解決問題として残されている。time reversalのような追加対称性がなければ表面状態が局在化する可能性がある。

### 8. Moore-Ran-Wenからの進展

Moore-Ran-Wen (2008) は $\chi = 1$ の特殊なHopf絶縁体を1つのハミルトニアンで実現した。本論文の進展：

1. **任意の整数Hopfインデックス**：一般化Hopf写像を用いて $\chi$ が任意の整数値を取る模型の族を構築。$\chi = \pm pq \cdot \Gamma(g)$。
2. **完全な位相図**：パラメータ $(t, h)$ 空間での位相図を $(p, q)$ ごとに決定。位相境界はギャップレス条件から解析的に求まる。
3. **表面状態のロバスト性の数値実証**：$U(1)$ のみを保持するランダム摂動下での安定性を系統的に調べた。Moore-Ran-Wenは表面状態の数値計算を行ったが、ロバスト性の検証はこの論文が初。
4. **Hopfインデックスの構成的理解**：$\chi = \Gamma(g) \cdot \chi(f)$ という分解により、Hopfインデックスが $\mathbb{T}^3 \to \mathbb{S}^3$ と $\mathbb{S}^3 \to \mathbb{S}^2$ の巻き付き数の積として理解できることを示した。
5. **Chern数がゼロの解析的証明**：パリティ議論によりすべてのChern数 $C_\mu = 0$ を証明（Hopfインデックスの整数値が well-defined であることの保証）。

- arXiv:2501.05376 -- "Correlated Hopf insulators" -- 理由：Hopf絶縁体のQBTとLuttinger半金属のQBTの関係を直接議論しており、我々のプロジェクトの中心的な論文。
