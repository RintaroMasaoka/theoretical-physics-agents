# Berry-dipole Semimetals
- **arXiv ID**: arXiv:2404.10049
- **Authors**: Zheng-Yang Zhuang, Chaoyi Zhang, Xiao-Jiao Wang, Zhongbo Yan
- **Year**: 2024
- **Source**: literature/papers/2404.10049/

## 我々の研究との関連性

本論文はHopf写像を用いて2バンドモデルを構成し、バンド縮退点がquadratic energy dispersionを持つ「Berry-dipole半金属」を導入する。これはHopf写像とQBT（quadratic band touching）を直接結びつける数学的構造であり、我々のHopf insulator表面QBTと相互作用系のQBTの接続研究に核心的に関連する。

## 抽出内容

### 1. Berry-dipoleの概念と定義

Berry dipoleは、Weyl nodeのBerry chargeの概念を双極子に拡張したものである。Weyl nodeがBerry曲率の磁気単極子（monopole）として振る舞うのに対し、Berry dipole nodeはBerry曲率が点双極子（point dipole）のような場の分布を示す。

物理的には、Berry dipoleは反対の位相電荷を持つ2つのWeyl nodeが無限に近づいて重なったものと解釈できる。通常、2つの反対電荷のWeyl nodeが衝突するとペア消滅するが、鏡映対称性で保護されている場合や、3D Hopf insulator相の臨界点として出現する場合には消滅が回避される。

定量的な定義として、Berry dipole nodeを囲む閉曲面上のBerry曲率の積分は全体としてゼロだが、上半分（$q_z > 0$）または下半分（$q_z < 0$）の曲面上での積分はそれぞれ量子化された非ゼロの値を持つ：

$$\frac{1}{2\pi}\int_{q_z \gtrless 0} \boldsymbol{\Omega}_\chi^{(c)}(\boldsymbol{q}) \cdot d\mathbf{S} = \mp 1$$

これは、Berry dipoleが2つの反対で無限に近いBerry chargeから形成されていることを反映している。

重要な性質として、**2つのBerry dipole nodeのBerry曲率は同一**であり、正味のBerry dipoleはWeyl半金属における正味のBerry chargeのようにゼロになる必要がない。

### 2. Hopf写像によるモデル構成

Hopf写像は$S^3 \to S^2$の写像であり、2成分複素スピノル $\zeta = (\zeta_1, \zeta_2)^T$ と3成分実ベクトル $\boldsymbol{d} = (d_x, d_y, d_z)$ の間の関係式で記述される：

$$d_x = 2\text{Re}(\zeta_1^* \zeta_2), \quad d_y = 2\text{Im}(\zeta_1^* \zeta_2), \quad d_z = |\zeta_1|^2 - |\zeta_2|^2$$

すなわち $d_i = \zeta^\dagger \sigma_i \zeta$ である。2バンドHamiltonianは $\mathcal{H}(\boldsymbol{k}) = \boldsymbol{d}(\boldsymbol{k}) \cdot \boldsymbol{\sigma}$ として構成される。

本論文では以下の複素スピノルを選択する：

$$\zeta_1(\boldsymbol{k}) = \lambda(\sin k_x + i \sin k_y)$$
$$\zeta_2(\boldsymbol{k}) = \delta(\cos k_x - \cos k_y) + i\left(M - t\sum_{i=x,y,z} \cos k_i\right)$$

$\delta = 0$ の場合のHamiltonian成分は：

$$d_x(\boldsymbol{k}) = 2\lambda M(\boldsymbol{k}) \sin k_y, \quad d_y(\boldsymbol{k}) = 2\lambda M(\boldsymbol{k}) \sin k_x$$
$$d_z(\boldsymbol{k}) = \lambda^2 \sin^2 k_x + \lambda^2 \sin^2 k_y - M^2(\boldsymbol{k})$$

ここで $M(\boldsymbol{k}) = M - t\sum_{i=x,y,z} \cos k_i$ である。

エネルギー分散は：

$$E_\pm(\boldsymbol{k}) = \pm [\lambda^2(\sin^2 k_x + \sin^2 k_y) + M^2(\boldsymbol{k})]$$

$t < M < 3t$ の場合、2つのバンドnodeが $\boldsymbol{k}_{n,\chi} = \chi(0, 0, \arccos(M/t - 2))$ に存在する。

### 3. QBTの起源とHopf写像構造との関係

バンドnode近傍の低エネルギーHamiltonianは（$\delta = 0$の場合）：

$$\mathcal{H}_\chi(\boldsymbol{q}) = 2\chi v v_z q_z q_y \sigma_x + 2\chi v v_z q_z q_x \sigma_y + [v^2(q_x^2 + q_y^2) - v_z^2 q_z^2] \sigma_z$$

ここで $v = \lambda$, $v_z = t\sqrt{1 - (M/t - 2)^2}$, $\boldsymbol{q}$ はnode位置からの運動量である。

低エネルギー分散は **全方向に2次**：

$$E_{\chi,\pm}(\boldsymbol{q}) = \pm [v^2(q_x^2 + q_y^2) + v_z^2 q_z^2]$$

QBTが出現する**位相的な理由**：

1. **次元還元の視点**：$k_z$を固定パラメータとして、3D BDSMを2D Hamiltonianの積み重ねとみなす。2つのBerry-dipole node間の$k_z$平面は（Chern数はゼロだが）**2D Hopf insulator**に対応する。

2. **条件付き位相的障害（conditionally obstructed Hamiltonians）**：$d_z(\boldsymbol{k}) = 0$ のゼロ値等高線と $d_x(\boldsymbol{k}) = d_y(\boldsymbol{k}) = 0$ の同時ゼロ値等高線の配置が、バルクギャップの閉塞なしには自明な配置に変形できない。これが非自明トポロジーの根拠となる。

3. **巻き数**：高対称線 $k_y = 0$ に沿った1次元Hamiltonianは $\sigma_x$ に関するカイラル対称性を持つ。$k_z$ 平面上の有効1D Hamiltonianの2つの項が複素関数 $[\lambda \sin k_x + i\tilde{M}(k_x, k_z)]^2$ の実部と虚部に等しいため、巻き数 $W(k_z) = 2$ となる。**巻き数2**が、時間反転対称性がなくてもペアのエッジ状態の存在と安定性を保証する。

つまり、QBTの出現はHopf写像が自然に生成する $d_i(\boldsymbol{k})$ の**非自明なゼロ値等高線配置**に根本的な原因がある。Hopf insulator相間の転移点としても、また2D Hopf insulator平面と自明平面の境界としても、Berry dipole nodeが出現する。

### 4. 位相不変量

Berry-dipole phaseを特徴づける位相不変量：

- **Chern数**：すべての $k_z$ 平面で $\mathcal{C}_1(k_z) = 0$（ゼロ）。これはWSMとの決定的な違い。
- **Berry dipole charge**：閉曲面の半分（$q_z > 0$ または $q_z < 0$）での積分が $\mp 1$ に量子化。
- **巻き数** $W(k_z)$：高対称線上のカイラル対称性に基づく1Dトポロジカル不変量。$|W_0^{(x)}(k_z)| = |W_0^{(y)}(k_z)| = 2$ （$-k_0 < k_z < k_0$ のとき）。
- **2D Hopf不変量**：$k_z$固定平面のHamiltonianが2D Hopf insulatorに分類される（Ref. Wang2015hopf）。

巻き数の計算式：

$$W_{0/\pi}^{(x)}(k_z) = \frac{1}{4\pi i}\int_{-\pi}^{\pi} dk_y \, \text{Tr}[\mathcal{S}_x \mathcal{H}_{k_z}^{-1}(k_x = 0/\pi, k_y) \partial_{k_y} \mathcal{H}_{k_z}(k_x = 0/\pi, k_y)]$$

ここで $\mathcal{S}_x = \sigma_y$ がカイラル対称性演算子である。

### 5. Hopf insulatorとの関係

本論文のモデルはHopf insulatorそのものではなく、Hopf写像という**同じ数学的構造**を用いた別の相（半金属相）である。

具体的な関係：

1. **Hopf写像の共有**：3D Hopf insulator、2D Hopf insulator、ノーダルリンク半金属、そしてBerry-dipole半金属はいずれもHopf写像 $\boldsymbol{d} = \zeta^\dagger \boldsymbol{\sigma} \zeta$ を基盤とする。スピノル $\zeta$ の選択によって異なる位相が実現される。

2. **次元還元によるつながり**：Berry-dipole node間の $k_z$ 平面は**2D Hopf insulator**を記述する。つまり、BDSMは2D Hopf insulator平面と自明平面の境界にBerry dipole nodeが位置する3D半金属である。これはWSMがChern insulator平面と自明平面の境界にWeyl nodeを持つのと類似。

3. **結晶Hopf insulator臨界点との関係**：先行研究（Nelson et al., 2021; arXiv:2111.09365）で、2つの異なる3D結晶Hopf insulator間の臨界点がpoint Berry dipoleであることが示されている。本論文のBDSMはそのような臨界点としてではなく、独立した半金属相としてBerry dipoleを実現する。

4. **2D Hopf insulatorとのつながり**：参考文献Wang & He (2015)に従い、2D二バンドHopf insulatorは10分類を超えた固定バンドトポロジカル絶縁体であり、3D Hopf insulatorと同様の位相構造を持つ。

### 6. 物理的帰結

#### Berry曲率の構造

$$\boldsymbol{\Omega}_\chi^{(c)}(\boldsymbol{q}) = -\boldsymbol{\Omega}_\chi^{(v)}(\boldsymbol{q}) = -\frac{2v^2 v_z^2 q_z \boldsymbol{q}}{[v^2(q_x^2 + q_y^2) + v_z^2 q_z^2]^2}$$

運動量依存性は $z$方向の点双極子の場の分布に類似。

#### 内因性異常Hall効果

$$\sigma_{xy}(\mu) = -\frac{2e^2}{\hbar} \frac{\sqrt{\mu}}{3\pi^2 v_z} = -\frac{2e^2}{h} \frac{D_{F,z}}{3\pi}$$

ここで $D_{F,z} = 2\sqrt{\mu}/v_z$ はFermi面の $z$ 軸方向の直径。$\sigma_{xz} = \sigma_{yz} = 0$。WSMではHall伝導度がWeyl node間の距離に比例する（かつ $\mu$ に依存しない）のに対し、BDSMでは $\sqrt{\mu}$ に比例する。

#### 軌道磁気モーメント

$q_z$ 軸上の $z$ 成分は定数：

$$m_z(0, 0, q_z) = -\frac{2ev^2}{\hbar} = -2\frac{e\hbar}{2M_{x(y)}^*} = -2\mu_B^*$$

有効Bohr磁子 $\mu_B^*$ の **2倍**。これは大質量Dirac fermionのバンド端での値（$1 \times \mu_B^*$）と異なる。

#### ゼロ磁場軌道磁化

$$\boldsymbol{M}(\mu) = -\frac{2e}{\hbar}\frac{\mu^{3/2}}{3\pi^2 v_z}\hat{z} = -2n_T \mu_B^* \hat{z} = \frac{\mu}{e}\sigma_{xy}(\mu)\hat{z}$$

すべての電子が同じ量子化された磁化に寄与する。

#### 異方的Landau準位

$z$方向磁場の場合（解析解あり）：

$$E_{\chi,0}(q_z) = v^2/l_B^2 - v_z^2 q_z^2$$
$$E_{\chi,n\pm}(q_z) = v^2/l_B^2 \pm (2nv^2/l_B^2 + v_z^2 q_z^2), \quad n \geq 1$$

全Landau準位が分離し、磁場強度に線形依存（$E \propto l_B^{-2} \propto B$）。

$x$方向磁場の場合（近似解）：

$$E_{\chi,1\pm}(q_x) = \pm \sqrt{2v^3 v_z/l_B^2} \, q_x$$
$$E_{\chi,n\pm}(q_x) = \pm [F_n v v_z / l_B^2 + G_n v^2 q_x^2], \quad n \geq 2$$

$F_n = 2\sqrt{n(n-1)}$, $G_n = (2n-1)/2\sqrt{n(n-1)}$。最もゼロに近い2つのLandau準位が線形分散を持ち、$q_x = 0$ で交差して1D非線形Dirac coneを形成する。$z$ 方向とは根本的に異なる振る舞い。

#### 表面状態

第1種BDSM（$\delta = 0$）：**同じスピン偏極を持つペアのFermi arc**。層Chern数がゼロにもかかわらず、巻き数 $W = 2$ により対向伝播するペアのエッジ状態が存在。Dirac半金属のペアFermi arcは時間反転対称性により反対のスピンテクスチャを持つが、BDSMは時間反転対称性を欠くため同じスピン偏極。

第2種BDSM（$\delta \neq 0$）：表面Fermi arcがギャップを開き、代わりに**ヒンジFermi arc**（各コーナーに1つのゼロエネルギー束縛状態）が出現。第1種から第2種BDSMへの直接的な転移。

### 7. Hopf写像からQBTへの数学的構造

Hopf写像がQBTを生み出す本質的な数学的要素：

1. **Hopf写像の2次性**：$d_i = \zeta^\dagger \sigma_i \zeta$ はスピノル成分の**双線型形式**であるため、$\zeta$ が $\boldsymbol{k}$ の1次関数であれば $d_i$ は自動的に2次となる。node近傍で $\zeta_1 \sim q_x + iq_y$ かつ $\zeta_2 \sim q_z$ のような線形依存性を持てば、エネルギー分散 $E = |\boldsymbol{d}|$ は2次になる。

2. **位相的保護**：巻き数 $W = 2$ がnode近傍のBerry位相 $2\pi$（ゼロ値等高線の非自明な絡み合い）を保証し、QBTの安定性に寄与する。

3. **$q_z = 0$ 平面でのbilayer grapheneとの類似**：$q_z = 0$ 平面に制限すると、低エネルギーBerry-dipole Hamiltonianは巻き数2の2次Dirac Hamiltonian（bilayer grapheneで広く研究されたもの）に帰着する。

4. **$\zeta$ のゼロ点構造**：$\zeta_1$ と $\zeta_2$ のゼロ値等高線のトポロジカルな絡み合いが、$d_{x,y,z}$ の非自明なゼロ値等高線配置を決定し、それが2D Hopf insulator位相（ひいてはBerry dipole node）の存在を保証する。
